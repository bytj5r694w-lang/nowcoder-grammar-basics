## 运行方式

环境：Python 3.8 及以上，只用标准库，无需安装依赖。

```bash
python "01_顺序结构程序设计/NC22206_乘法表.py"
```

或把样例输入重定向进程序：

```bash
echo "2 1" | python "02_选择结构程序设计/NC212955_比大小.py"
```

## 几个实现上的说明

- **NC215089 默契**：题目样例里相等时输出的是全角感叹号 `Tacit！`，不相等时是半角 `No Tacit!`，两者不能混用。
- **NC14703 素数回文**：拼接后的回文数最多 17 位，试除法会超时，改用 Miller-Rabin 判素。
- **NC200369 四舍五入**：把小数压成一个整数来模拟进位，避免逐字符处理小数点；贪心地对"最靠左的 ≥5 的小数位"进位，收益最大。
- **NC205911**：方差用 `(n·Σai² - (Σai)²) / n²` 的整数公式计算，避免大数浮点误差。
